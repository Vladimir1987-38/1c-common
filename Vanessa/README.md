Подготовлено 16.10.2026 в рамках PRJ-4263. Схема: отдельная файловая база менеджера, внешняя обработка Vanessa Automation, расширение client_mcp в менеджере и VAExtension в тестируемой базе.

1. [Развёртывание менеджера и MCP](docs/deployment.md) — для разработчика, который готовит новый стенд.
2. [Подключение проекта тестирования](docs/project-setup.md) — папки проекта, профиль клиента и проверка связи.
3. [Использование и настройка](docs/usage.md) — подготовка и запуск сценариев, результаты, таймауты и диагностика.

Общие правила работы агента: [vanessa-mcp](../skills/vanessa-mcp/SKILL.md). Сценарии каждой конфигурации хранятся в её проекте, в Vanessa/Scenarios.

## Файлы для развёртывания

Поставка хранится отдельно от Git на странице [«Vanessa — сценарное тестирование 1С» в Wiki](https://wiki.spb.teremok.ru/pages/viewpage.action?pageId=163548689). Из-за ограничения размера запроса ZIP разделён на девять вложений vanessa-1.2.043.45.zip.001–009. Скачайте все части в одну папку и соберите ZIP по инструкции на странице. Размер собранного архива — 37 428 546 байт; SHA-256: 2865A3B7FCBD63EED2A8CEE5C56C702C00C0CC640CA2CCE2DECF810A7FB81168. После проверки распакуйте архив в Vanessa/distributions/1.2.043.45. На существующем рабочем месте файлы сохранены локально; distributions, packages и ZIP исключены из Git.

После распаковки комплект находится в [distributions/1.2.043.45](distributions/1.2.043.45/); ссылки ниже относятся к локальным файлам:

Это предоставленный пользователем комплект для установки, а не полная выгрузка исходников всех EPF/CFE для пересборки. Версия client_mcp по истории получения — v0.6.6; имя файла её не содержит. Файлы при копировании не пересобирались и не изменялись. Проверка 16.10.2026: все 5 107 файлов (51 243 343 байта, около 48,9 МиБ) совпадают с предоставленным каталогом по SHA-256. Не считать лежащий здесь VAExtension автоматически идентичным расширению, которое ранее адаптировали в конкретной базе.

Для разработки самих инструментов нужны отдельные исходники соответствующих версий: [Vanessa 1.2.043.45](https://github.com/Pr-Mex/vanessa-automation/tree/1.2.043.45), [client_mcp v0.6.6](https://github.com/1c-neurofish/onec-client-mcp-devkit/tree/v0.6.6). Для установки использовать готовые файлы комплекта.

Сохранены входящие в поставку [лицензии](distributions/1.2.043.45/vanessa-automation/licenses/) и документация. Платформа 1С, её лицензии, файловая база менеджера, тестовые базы, профили с учётными данными и личные настройки разработчика в комплект не входят. Наличие файлов не доказывает готовность нового стенда: проверка описана в инструкции.

## Размещение и обновление

- Инструкции для новых развёртываний хранятся в Git в 1c-common/Vanessa; файлы поставки получают отдельно архивом.
- На каждом рабочем месте копировать комплект в отдельный локальный каталог инструментов. Базу менеджера хранить вне репозитория.
- Исходная рабочая копия пользователя сохранена, поскольку её путь использует действующий менеджер. Переключение его ярлыка и каталогов библиотек на новую копию выполняется при отдельном обслуживании.
- Новые версии добавлять соседними каталогами, затем проверять на отдельном стенде. Не заменять файлы, из которых выполняется тест.
- Git-копия библиотеки содержит инструкции, но не distributions и не архив поставки. При передаче папкой комплект можно передавать отдельно целиком. Сохраняйте лицензии; настройки баз и секреты остаются локальными.

Связь MCP, связь с нужным клиентом и успешный сценарий — три отдельные проверки. Сохранение комплекта не выполняет ни одну из них автоматически.
