# Общие инструменты проектов 1С

Рабочие правила и навыки редактируются только здесь. Папка должна находиться рядом с Analitics, B4_coupone, Fusion_manager, KSO, QualityCheck, UT 11, Оперучет и Kassa 1C.

- [Правила работы](rules/workflow.md).
- [Стандарты разработки 1С](rules/1c-development.md).
- [Пакетные операции](skills/1c-batch/SKILL.md).
- [Работа с Jira](skills/jira-workflow/SKILL.md).
- [Синхронизация проекта и сеансы 1С](skills/1c-project-sync/SKILL.md).

В каждом проекте AGENTS.md подключает общие правила, а doc/AGENTS.md описывает одинаковое для всех проектов подключение общих инструментов. В .agents/skills находятся короткие точки входа: они читают соответствующий общий SKILL.md. Символические ссылки не используются: на текущем компьютере их создание требует прав администратора.

Скрипты 1С запускаются из корня целевого проекта по пути ../1c-common/skills/1c-batch/scripts/. Настройки .1c-devbase.* остаются в целевом проекте. Для Jira в первую очередь использовать подключённый в Codex MCP-сервер `jira`; отдельный файл настройки при этом не требуется. Единые настройки резервного подключения Jira хранятся в 1c-common/.jira-devbase.ps1 и исключены из Git. Работа с Jira выполняется через MCP-сервер http://jira-mcp.teremok-spb.local:9000/mcp. В общем файле задаются JIRA_MCP_URL и JIRA_MCP_TOKEN (токен приложения MCP); прежние REST-параметры не используются. Порядок перехода описан в [подключении Jira](skills/jira-workflow/references/connection.md). Параметры резервного подключения Jira редактировать только в этом общем файле. Операции проекта запускать из его корня; настройки баз 1С сюда не переносить.

После переноса рабочей папки сохраняйте расположение 1c-common рядом с проектами. Старые пути .agents/skills/1c-batch/scripts/ заменены общими путями; содержимое журналов прошлых задач не является инструкцией запуска.

Резервные копии до миграции хранятся в .migration-backup/2026-09-07/ в ZIP-архивах по проектам. Это снимки для отката, а не редактируемые источники правил. Они исключены из Git. Не распаковывайте их поверх текущих файлов без сравнения изменений.

Папка 1c-common имеет собственный Git-репозиторий; коммиты и публикация выполняются отдельно по запросу. Исходные проекты остаются отдельными репозиториями.

После изменения имени или описания навыка обновить точки входа командой tools/connect-project.ps1 -ProjectRoot <путь проекта> для каждого проекта. При изменении рабочих инструкций или скриптов обновление точек входа не требуется.
