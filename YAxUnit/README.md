# Общий комплект YAxUnit

Подготовлено 19.10.2026 в рамках PRJ-4263. Комплект создаёт файлы проектов; установку в базы и запуск тестов выполняют отдельно.

- [engine/25.12/YAXUNIT](engine/25.12/YAXUNIT/Configuration.xml) — полная XML/BSL-выгрузка движка YAXUNIT 25.12 из имеющегося тестового стенда кассы. 390 исходных файлов сохранены без изменений; дополнительно приложена [лицензия Apache 2.0](engine/25.12/YAXUNIT/LICENSE) из выпуска 25.12. Совпадение этой выгрузки с официальным CFE побайтно не заявляется.
- [template/extensions/Tests](template/extensions/Tests/Configuration.xml) — шаблон Tests с языком Русский, без общих модулей, процедур, регистраций и тестовых данных кассы. Удалена привязка языка к UUID основной конфигурации кассы; UUID объектов шаблона сохранены. ConfigDumpInfo.xml кассы не копируется, его создаёт платформа при выгрузке.
- [initialize-project.ps1](../skills/yaxunit/scripts/initialize-project.ps1) — подготовка каталогов без подключения к базам и без перезаписи существующих расширений, тестов и настроек.

Исходники движка и архив поставляются отдельно от Git через [Wiki: YAxUnit](https://wiki.spb.teremok.ru/pages/viewpage.action?pageId=163548690). В Git остаются эта инструкция, скрипты и пустой шаблон Tests. Каталоги engine и packages общей библиотеки исключены из Git; исходники расширений отдельных проектов остаются в extensions/<имя>.

## Получить поставку после клонирования

1. Скачайте с Wiki обе части yaxunit-25.12-project-kit.zip.001 и .002. Соберите ZIP командой на странице и проверьте SHA256: 30FD4D9A53503196C23393D43F5A0D06860FEE6EE619AFD992EECD85D242F9D7. Размер ZIP — 4 977 300 байт.
2. Распакуйте проверенный архив в отдельную пустую папку. В нём 398 файлов: 390 исходных файлов движка, LICENSE, 6 файлов шаблона и README.txt.
3. Скопируйте engine/25.12/YAXUNIT в 1c-common/YAxUnit/engine/25.12/YAXUNIT. Если движок уже есть, сначала сравните версию и содержимое. Не заменяйте его автоматически.
4. Папка template в архиве — снимок пустого шаблона для восстановления. При наличии шаблона из актуального Git сохраняйте его; не заменяйте Tests существующих проектов.
5. После подготовки движка выполните подключение проекта ниже. Инициализатор проверяет наличие общего комплекта до изменения файлов проекта.

## Подключение проекта

Из корня проекта, расположенного рядом с 1c-common:

~~~powershell
& '../1c-common/tools/connect-project.ps1' -ProjectRoot '.'
~~~

Для добавления только файлов YAxUnit в уже подключённый проект:

~~~powershell
& '../1c-common/skills/yaxunit/scripts/initialize-project.ps1' -ProjectRoot '.'
~~~

Скрипт создаёт:

~~~text
extensions/YAXUNIT/                  движок 25.12 и лицензия
extensions/Tests/                   пустое Tests
tests/yaxunit/README.md              дальнейшие действия
tests/yaxunit/test-config.example.json
tests/yaxunit/test-config.local.json локальный путь результатов; исключён из Git
tests/yaxunit/results/               локальные отчёты; исключены из Git
~~~

При существующей папке extensions/YAXUNIT движок сохраняется; автоматически другая версия не устанавливается. Существующие extensions/Tests и настройки tests/yaxunit сохраняются. Старый каталог tests/yaxunit/extension переносится в extensions/Tests без изменения содержимого; при наличии обоих каталогов скрипт останавливается без объединения. Частично созданный/нестандартный комплект нужно разобрать отдельно: повторный вызов не очищает тесты и не ремонтирует папку перезаписью. Обновление движка — отдельная операция с проверкой изменений проекта.

## Готовность и ограничения

Файлы подготовлены, но совместимость с конкретной конфигурацией, установка в базе, права и клиент этим не подтверждены. Пустое Tests содержит ноль тестов; считать такой прогон успешной проверкой запрещено. Готовые тесты кассы остаются в её проекте и не распространяются в другие проекты.

Для установки допускается официальный [YAxUnit-25.12.cfe](https://github.com/bia-technologies/yaxunit/releases/download/25.12/YAxUnit-25.12.cfe); XML/BSL здесь предназначены для конфигуратора и разработки. Перед загрузкой проверить требования платформы, язык Русский и существующие расширения. Правило кассы о толстом клиенте не распространяется на другие проекты. Для мобильных проектов отдельно определить тестирование на настольной платформе; работа на мобильной платформе не подтверждена.
