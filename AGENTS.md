# Общие инструменты 1С

Это библиотека правил и навыков, а не информационная база. Перед изменениями прочитать README.md и rules/workflow.md. Изменять общую реализацию здесь; локальные файлы .agents/skills в проектах служат только для её обнаружения. При изменении name или description навыка обновить соответствующие точки входа во всех подключённых проектах.

При сопровождении библиотеки можно изучать и изменять её скрипты. При обычной работе с базами использовать описанный интерфейс. Реальные файлы подключения не читать и не выводить.

Проверять ссылки, YAML навыков и синтаксис изменённых PowerShell-скриптов. Проверки структуры не должны запускать 1С или записывать данные в Jira.
